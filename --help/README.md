# --help

HashtagCMS Node.js Frontend Renderer

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure your environment:
   - Edit `.env` with your HashtagCMS backend details

3. Build assets:
   ```bash
   npm run build
   ```

4. Start the server:
   ```bash
   npm start
   ```

5. Visit http://localhost:3000

## Documentation

See the `docs/` folder for comprehensive documentation.

## Development

- `npm run server` - Start dev server with auto-reload
- `npm run dev` - Watch and rebuild assets
- `npm run build` - Build production assets
