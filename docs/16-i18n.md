# Internationalization (i18n)

Guide to multi-language support.

## Overview

The system supports multiple languages through:
- Language detection from URL
- Translation files
- Language-specific content from CMS

## Language Detection

### URL Structure

```
/en/blog        → English
/es/blog        → Spanish
/fr/blog        → French
```

### Default Language

```javascript
// If no language in URL, defaults to 'en'
const lang = urlInfo.language || 'en';
```

## Translation Files

**Location:** `locales/{lang}/hashtagcms/`

### Example: locales/en/hashtagcms/common.json

```json
{
    "readMore": "Read More",
    "contactUs": "Contact Us",
    "submit": "Submit"
}
```

### Example: locales/es/hashtagcms/common.json

```json
{
    "readMore": "Leer Más",
    "contactUs": "Contáctenos",
    "submit": "Enviar"
}
```

## Using Translations

### In Views

```ejs
<%= helper.trans('hashtagcms::common.readMore') %>
```

### In Controllers

```javascript
const helpers = this.createViewHelpers('en');
const text = helpers.trans('hashtagcms::common.readMore');
```

## Language Switching

### Language Links

```ejs
<a href="/en/blog">English</a>
<a href="/es/blog">Español</a>
<a href="/fr/blog">Français</a>
```

### Current Language

```ejs
Current: <%= cms.meta.lang.name %> (<%= cms.meta.lang.isoCode %>)
```

## Best Practices

1. **Use Translation Keys**: Don't hardcode text
2. **Consistent Keys**: Use same keys across languages
3. **Fallback**: Always provide English translation
4. **Test**: Test all languages
